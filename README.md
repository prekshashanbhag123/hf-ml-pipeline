# Hugging Face ML Pipeline

A modular machine learning pipeline using Hugging Face Transformers and PyTorch for model training, evaluation, and inference.

## 🚀 Features
- Load and fine-tune transformer models
- Dataset preprocessing using Hugging Face Datasets
- Training pipeline with Trainer API
- Simple evaluation and inference

## 🧠 Tech Stack
- Python
- PyTorch
- Hugging Face Transformers
- Datasets
